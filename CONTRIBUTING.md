# Contributing

Open a focused issue or pull request describing the problem, resulting behavior and validation. Use Node 24, `npm install`, `npm test`, `npm run typecheck` and `npm run build`; no credentials are needed for automated checks.

Keep Korean-first copy natural and English equivalent. Preserve infrastructure disclosure, MIT attribution and vendor license notices. Do not describe market movement as guaranteed profit or verified arbitrage.

Never commit `.env`, personal identifiers, databases, backups, logs or tunnel state. Use isolated fixtures in tests. Keep execution/mainnet disabled; financial or wallet changes require explicit review and their existing acceptance gates. See [SECURITY.md](SECURITY.md) for private reports.

Make real, useful commits. Do not manufacture daily history or contribution activity for community tracking.
